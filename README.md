# 🧠 I+1 — English Learning App

> Um aplicativo web moderno e interativo focado na aquisição acelerada de vocabulário e na prática de inglês, desenvolvido através de engenharia de prompt avançada e *vibecoding*.

## 🎯 Sobre o Projeto

O **I+1** nasce da premissa de otimizar a assimilação de novos termos e estruturas em inglês de forma fluida, limpa e imersiva. Concebido como uma ferramenta de alta performance para estudantes de idiomas, o app combina uma interface elegante (Dark Mode nativo) com micro-interações fluidas para tornar o aprendizado diário dinâmico e eficiente.

## 🛠️ Tecnologias & Arquitetura

O projeto foi construído utilizando um ecossistema frontend moderno e de alta performance:

* **Framework:** React / TanStack Start
* **Linguagem:** TypeScript
* **Estilização:** Tailwind CSS
* **Plataforma de Desenvolvimento:** Lovable

---

## ✨ Principais Funcionalidades

* **Interface Responsiva & Mobile-First:** Experiência otimizada tanto para desktop quanto para dispositivos móveis.
* **Design Minimalista:** Foco total no conteúdo e na experiência do usuário (UX), evitando distrações visuais.
* **Ciclos de Vocabulário Dinâmicos:** Estrutura pensada para retenção de longo prazo.
